Checklist de Montagem — Modelo VIC no SharePoint

Caminho sem código (web parts nativas + Tema CAIXA). Marque cada etapa concluída.

A · Preparação (uma vez)

  • Criar o Site de Comunicação “VIC — Versionamento e Integração de Código”.
  • Definir o logo do site com vic-icon (SVG ou PNG).
  • Aplicar o Tema CAIXA: registrar com vic-caixa-theme.ps1 e selecionar em ⚙ Alterar a aparência → Tema.
  • Subir as ilustrações (pasta ilustracoes-png/) na Biblioteca de Ativos do Site.
  • Configurar a navegação superior: Visão Geral · Práticas Desejadas · Tríade Técnica · Análise e Acompanhamento.
  • Criar as páginas vazias: Visão Geral, Práticas Desejadas, Prática 1–13.
Dica: abra o protótipo com ?sp=1 (botão “Mapa SharePoint”) ao lado deste checklist — as etiquetas dizem a web part de cada bloco.

B · Página “Visão Geral” (inicial)

  • Seção largura total + Herói: título “Versionamento e Integração de Código” + subtítulo.
  • Texto: “Qual a finalidade deste modelo?”.
  • Texto (realce) ou Chamada para ação: aviso “Modelo determinístico”.
  • Links Rápidos: tecnologias de referência (Git · Azure DevOps/GitHub · GitFlow/GitHub Flow · SemVer).
  • Texto: “Missão do modelo” (lista de 6).
  • Links Rápidos: “Benefícios” (7 itens).
  • Botão/Chamada para ação: “Acessar as Práticas Desejadas”.
  • Definir como página inicial do site.

C · Página “Práticas Desejadas” (hub)

  • Herói ou seção “Destaque forte” + Texto: título “Práticas Desejadas”.
  • Texto: introdução (jornada de maturidade).
  • Links Rápidos com 13 itens, cada um linkando para a página da prática.

D · Modelo de página de Prática repetir 13×

Blocos (na ordem)

  • Seção “Destaque forte” + Imagem/Herói: capa com nº + título da prática.
  • Texto (realce) ou Chamada para ação: a caixa “Regra”.
  • Texto: “O que a prática exige” (lista).
  • Imagem: ilustração da prática (quando houver).
  • Texto (tabela): tabelas (Práticas 11 e 12).
  • Texto/Link: “Referências metodológicas”.
Monte uma página perfeita e duplique (Configurações da página → Copiar) para as demais, trocando número, título, regra e imagem.

E · Conferência final

  • Tema CAIXA aplicado em todas as páginas (azul institucional).
  • Navegação superior funcionando (4 seções).
  • Todas as ilustrações carregando (imagens, não links quebrados).
  • Links dos cards do hub apontando para as práticas certas.
  • Revisão de texto: tom impositivo mantido (“deve”, “é obrigatório”).
  • Páginas publicadas (não em rascunho).
